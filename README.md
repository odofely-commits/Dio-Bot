# Dio-Bot 💜

> ≽^•ˑ•ྀི≼ *¡Hola! Soy Dio, tu bot supremo* ≽^•ˑ•ྀི≼

Bot de WhatsApp con comandos de nekos, juegos, economía y mucho más. Hecho con Baileys y puro estilo aesthetic.

## ✨ Características

- 📸 **Acciones** — hug, kiss, pat, slap y más
- 🖼️ **Imágenes** — nekos, waifus, maids, etc.
- 🎮 **Juegos** — trivia, 8ball, truth or dare
- 💰 **Economía** — sistema de puntos y nivel
- 🛡️ **Moderación** — warn, mute, kick, ban
- 👤 **Perfil** — avatar, estadísticas, perfil
- 🎵 **Música** — buscar y reproducir
- ⚙️ **Utilidades** — help, ping, owner

## 🚀 Instalación

### Requisitos
- **Node.js** v16 o superior
- **npm** o **yarn**
- **WhatsApp**

### Pasos

1. **Clonar el repositorio**
```bash
git clone https://github.com/odofely-commits/Dio-Bot.git
cd Dio-Bot
```

2. **Instalar dependencias**
```bash
npm install
```

3. **Configurar variables de entorno**
```bash
cp .env.example .env
```

4. **Iniciar el bot**
```bash
npm start
```

5. **Escanear QR**
- Se generará un código QR en la terminal
- Escanéalo con WhatsApp
- ¡Listo! El bot está activo
